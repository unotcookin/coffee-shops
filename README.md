# Naples Coffee Tour

A lightweight, mobile-friendly interactive web application designed to guide coffee lovers through a curated tour of local coffee shops, mobile carts, and artisanal roasters across Naples, Marco Island, and surrounding areas.

---

##  What It Is

The **Naples Coffee Tour** app serves as a personal companion for exploring the local coffee scene. Built entirely as a single-file HTML application (HTML, CSS, and vanilla JavaScript), it requires no installation, backend server, or app store download—just open it in any modern browser and start exploring.

---

##  Key Features

* **Curated List:** Features over 30 unique local coffee spots, complete with recommended drinks, food pairings, operating hours, and vibes.
* **Interactive Zone & Area Filters:** Easily filter locations by major zones (*Naples*, *Marco Island*, *Mobile Carts*) and drill down further by specific neighborhoods (*North Naples*, *Downtown*, etc.).
* **Visit Tracker & Progress Bar:** Tap the checkmark on any shop card to mark it as "visited." Watch your progress bar update in real-time as you work your way through the tour!
* **Persistent Storage:** Your visited spots and dark/light mode preferences are automatically saved locally in your browser (`localStorage`), so you never lose your progress.
* **Dark & Light Mode:** Seamlessly switch between a soft, forest-green light theme and a high-contrast deep dark theme designed for comfortable viewing anytime of day.
* **Expandable Details & Maps:** Tap "More Info & Hours" to reveal seating options, atmosphere details, and a direct link to open the location instantly in Apple Maps.

---

##  Built With

* **HTML5**
* **CSS3** (Custom Properties / CSS Variables for seamless theming)
* **Vanilla JavaScript** (ES6+)

---

##  How to Use

1. Save the application code into a file named index.html.
2. Double-click the file to open it in any web browser (Chrome, Safari, Edge, Firefox), or host it via GitHub Pages / Netlify to access it on your phone on the go.
3. Tap the theme toggle button in the header to switch between light and dark modes.
4. Use the filter buttons to narrow down your search, tap locations for details, and check them off as you visit them!
